# Changelog

## 1.0.0 — 2026-10-09

- Paneles independientes de jugadores y NPCs con posición, ancho y orden guardados por navegador.
- Colapso de paneles y barras individuales; retratos con acceso a acciones.
- Cinco accesos rápidos: Acciones, Conjuros, Dotes, Objetos y Abrir ficha.
- Estilos Clásico, D. Dungeon y Velvet Eclipse.
- Grupo automático/manual, soporte de actores de tokens no vinculados y permisos de propietarios.
- Integración opcional para reemplazar los paneles laterales de VND Enhanced.
- Soft gate de Patreon compartido mediante Velvet License Hub 2: todas las funciones permanecen disponibles.
- Recordatorio local para el GM si el Hub no está disponible; sin duplicar su tarjeta compartida.
- Traducciones inglés/español compatibles con la API de Foundry v14.

Validado con pruebas de lógica y navegador con APIs simuladas de Foundry. Se recomienda comprobar la convivencia con los demás módulos del mundo antes de una sesión.
